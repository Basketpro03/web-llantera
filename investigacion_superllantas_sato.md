# Brief: Sitio Web — Super Llantas Sato

Eres un agente encargado de construir el sitio web oficial de **Super Llantas Sato**, una empresa dedicada a la venta de llantas y servicios automotrices con presencia en Sinaloa y Baja California Sur, México. Este documento contiene toda la información necesaria para construir el sitio.

---

## 🎨 Identidad Visual

### Logo
- **Archivo:** `logo.png` — guardarlo en la raíz del proyecto (`D:\CLAUDE CODE\WEB LLANTERA\logo.png`)
- **Fondo:** Transparente (PNG con alpha) — úsalo directamente sobre cualquier fondo
- **Descripción visual:** Ícono de una "S" en rojo con borde blanco dentro de un círculo negro (simula el perfil de una llanta). A la derecha, texto "Llantas Sato" en rojo con borde blanco, tipografía bold italic estilo deportivo.
- **Uso recomendado en web:** Header sobre fondo negro o muy oscuro para máximo contraste

### Paleta de Colores

| Rol | Color | Hex |
|---|---|---|
| **Primario** | Rojo | `#CC0000` |
| **Oscuro / fondo header** | Negro puro | `#000000` |
| **Contorno / texto claro** | Blanco | `#FFFFFF` |
| **Fondo de secciones** | Gris claro | `#F5F5F5` |
| **Texto general** | Gris oscuro | `#1A1A1A` |

> Los colores rojo `#CC0000`, negro `#000000` y blanco `#FFFFFF` son los 3 colores del logo. Úsalos como base del sistema de diseño completo del sitio.

### Tipografía recomendada
- **Títulos:** Montserrat Bold (700)
- **Cuerpo:** Montserrat Regular (400)
- Fuente: Google Fonts — `https://fonts.google.com/specimen/Montserrat`
